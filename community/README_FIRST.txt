SMW ROM Hack Tracker Community Builder
=====================================

1. Close every Excel window.
2. Double-click BUILD_COMMUNITY_TRACKER.bat.
3. Enter your GitHub repo as owner/repository.
4. The builder creates SMW_ROM_Hack_Tracker_Community.xlsm.

The builder adds incremental Refresh Hacks, Random Hack Finder filters/button, rating columns, and Very Hides support sheets.
