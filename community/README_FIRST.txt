SMW ROM Hack Tracker Community Builder
=====================================

This folder contains your uploaded workbook as the source template:

SMW_ROM_Hack_Tracker_Community.xlsx

To create the shareable macro-enabled workbook:

1. Close every Excel window.
2. Double-click BUILD_COMMUNITY_TRACKER.bat.
3. Optionally enter your GitHub repo as owner/repository.
4. The builder creates SMW_ROM_Hack_Tracker_Community.xlsm.

If the builder cannot import the VBA module:

Excel > File > Options > Trust Center > Trust Center Settings > Macro Settings
Enable:
Trust access to the VBA project object model

Then close Excel fully and run the builder again.

Share the generated .xlsm through a GitHub Release.
