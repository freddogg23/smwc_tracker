MAINTAINER BUILD STEP
=====================

1. Close every Excel window.
2. Double-click BUILD_COMMUNITY_TRACKER.bat.
3. The script creates SMW_ROM_Hack_Tracker_Community.xlsm.
4. Test Refresh Hacks and Add Custom Hack.
5. Upload the XLSM to a GitHub Release for community downloads.

The XLSX file is the clean source template. The XLSM file is the finished public release.
